# ORRERY
A 3D Sun–Earth–Moon explorer built with React, Three.js, React Three Fiber and Astronomy Engine.

## Run locally
`npm install` then `npm run dev`.

## GitHub Pages
Create a repository named **ORRERY-3D**, upload all files including `.github`, and set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. The Vite base path is configured for `/ORRERY-3D/`.

Body sizes and Moon distance are visually exaggerated; positions and lunar phase are calculated with Astronomy Engine.
